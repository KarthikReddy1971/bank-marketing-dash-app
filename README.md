# Bank Marketing Analytics Dashboard 📊

An interactive web application built with **Python**, **Dash**, and **Plotly** to analyze customer demographics, account balances, and term deposit subscription trends.

---

## 🚀 Tech Stack
* **Frontend/Backend:** Dash, Plotly
* **Data Processing:** Pandas, NumPy

---

## 🛠️ Setup & Installation

1. **Clone or download** this project folder.
2. **Place your dataset** (`bank_market.csv`) directly into the root project directory (in the same folder as `app.py`).
3. **Install required dependencies** by running this command in your terminal:
   ```bash
   pip install dash pandas numpy plotly gunicorn

```

---

## ▶️ How to Run

1. Open your terminal or VS Code inside the project folder.
2. Run the application script:
```bash
python app.py

```


3. Open the local URL provided in your terminal (usually **`http://127.0.0.1:8050/`**) in your web browser.

---

## ✨ Features

* **Dynamic Filters:** Filter data by Job, Marital Status, and Subscription status.
* **KPI Cards:** Real-time metrics tracking Total Customers, Average Balance, and Total Subscribers.
* **Interactive Visualizations:** Age distribution histograms, job breakdown charts, balance vs. age scatter plots, and subscription share pie charts.
